# 말투표 (번역 스타일 가이드)

화자 근거: `work/speakers.json`(zeldaret/tmc 디컴파일 대조, `tools/speaker_map.py`) + 일본어 말투 집계.
검수 앱 각 메시지 머리에 **화자**가 표시됨. `[EZLO2]`처럼 대괄호는 직접 참조가 없어 블록 분류만 아는 경우.

> 인물 이름 표기는 일단 기존 한글판을 따름(용어집에서 최종 확정).

## 공통 규칙

1. **말끝이 캐릭터다.** 일본어의 1인칭·말끝 표지를 한국어 말끝(하게체/해라체/해요체/하십시오체/말버릇)으로 일관되게 옮긴다. 같은 인물은 블록이 달라도 같은 말투.
2. **`<name>` 뒤 조사 금지.** 이름은 플레이어 입력이라 받침 유무를 모름 → `<name>이/가`, `<name>을/를`, `<name>아/야` 쓰지 않는다.
   - 부름: `<name>！` / `<name> 군` / `<name> 님` (일본어 `くん`→`군`, `さま`→`님`)
   - 문장 속: `<name> 군은`, `<name> 님을`, 또는 문장을 바꿔 조사가 필요 없게
3. **링크 호칭**은 인물별 표를 따른다(아래 "링크를 부르는 말").
4. 효과음 `<sound:XXXX>`는 화자 목소리 단서이기도 함(에제로 0090~0092·008D·008E, 고론 01B7·01B8, 텟신 00D0).
5. 말버릇(`ゴロ`, `ッピ`, `アル`, `ザマス`, `ベイベ` 등)은 **지우지 말고** 한국어 말버릇으로 살린다(기존 한글판은 대부분 지워서 캐릭터성이 사라짐).

## 사투리·특수 말투

| 원문 | 위치 | 한국어 |
|---|---|---|
| 교토 사투리(やらはります, ほな, ぶぶづけ) | 블록62 | 느긋하고 은근히 비꼬는 **충청도/양반 말투** 권장("~하시겄슈?") |
| 시골 말투(〜だ○よ, 〜だべ, 〜だよ) | 블록41 (단페이 등) | 구수한 **시골 사투리**("~구먼유", "~혀") |
| 타론(〜だ○よ, 블록33) | 론론 목장 | 느긋한 시골 아저씨 **하게체**: "~구먼", "~게나", "~겠네", 링크=자네. 충청도 느낌은 가끔만("~말이여", "~이여"). "~유" 쓰지 않음 (2026-11-02) |
| ベイベ, 〜だぜ | 블록27 | 건들거리는 **반말**+"베이베" 유지 |
| ウオッホン, 카타카나 영어 | 블록77 | 영어 단어 그대로 섞기 |
